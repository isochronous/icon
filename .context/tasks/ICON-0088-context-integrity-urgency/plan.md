## Task: ICON-0088
## Branch: feature/ICON-0088-context-integrity-urgency
## Objective: Encode a maintenance-urgency rule into ICON's behavior: `.context/` maintenance belongs to the ticket that surfaced the need; **inaccurate `.context/` content is poison** and is fixed or expunged the moment it is identified; a need surfaced outside an active ticket becomes its own task; and mechanical obligations (e.g. oversized-file splits) are never deferred — a prior task having deferred one makes it more urgent, not acceptable.

## Decisions
- **Placement: full rule on-demand, minimal always-loaded trigger.** At decision time the manager session measured **8,621 words vs the ADR-008 8,500-word cap** (already over), with `agents/manager.agent.md` at **+408 words vs its 4,148 baseline** — 17 words below the ≥425 cumulative-drift re-inventory trigger. (Post-edit measurement is 8,685 / +472; see `word-count-snapshot.md`, which is now the ADR-008 baseline.) So the *normative* rule text goes into the on-demand, already-shipped `skills/context-maintenance/SKILL.md` (zero always-loaded cost), and `agents/manager.agent.md` gets only the minimum needed to make the manager actually *fire* it. Same placement-by-token-budget reasoning as ICON-0079 and ADR-008-lean placement in ICON-0084.
- **Not shipped as a `context_template/` standard.** This is agent-behavior governance, delivered through the skill surface that every consumer already loads. Adding a `context_template/context/standards/` file would push the rule into consumer *project* standards (where it does not belong), and force an `iconrc.json` template-version bump for no consumer benefit. Consumers get the rule via `context-maintenance`.
- **ICON's own `.context/standards/in-task-maintenance.md` is extended, not duplicated.** It already carries the mechanical-vs-design test and the "the edit that caused it owns the fix" rule; it lacks the inaccuracy-is-poison **immediacy** tier and the "deferral precedent does not create license" rule. Extend the existing standard (its `rules-index.md` row already exists → no index change).
- **ADR-008 obligations are discharged in this task, not deferred.** Any addition to `manager.agent.md` over ~17 words trips ADR-008's mandatory cumulative-drift re-inventory. Deferring that would be the exact failure mode this task's rule exists to prevent, so the re-inventory (fresh word-count snapshot superseding the ICON-0033 one + ADR-008 baseline/Consequences update) is in scope here.
- **Split-exemption boundary is *shape*, not *readership* (maintainer ruling).** The first draft asked whether an agent reads the file to decide what to do *now* vs to look up what was true *then*, which forced an awkward three-property special case for `.context/retrospectives.md` — a file that is genuinely both. The maintainer ruled `retrospectives.md` exempt, which moved the axis to shape: is the file's organizing axis *time* (entries appended in sequence, never reorganized) or *topic* (sections grouping subject areas)? This resolves every case cleanly, deleted the special case, and — noted by @reviewer — coincides with a precondition the gate already enforces mechanically, since a chronological log has zero peer `##` sections and so fails the gate's own ≥3-section requirement anyway. Readership was orthogonal to any mechanism; shape is not.
- **The distributed-template arm is scaffolds only, and its test is conjunctive (maintainer ruling).** "If we distribute it, don't split it" taken literally exempts template *seeds* (`domains/entities.md`, `standards/code-style.md`, …) — the very files the other arm names as the split rule's purpose — and its `/upgrade-repo`-divergence rationale doesn't hold for them, since upgrade doesn't overwrite populated files and seeds are meant to diverge. So the arm requires **both** a template counterpart **and** fixed-shape-scaffold status (structure is a parse contract). Path resolution goes through the `find-context-template` idiom, because a bare `context_template/` path doesn't exist in an installed consumer repo.
- **Satellite sites point by reference; only the canonical site enumerates.** A parenthetical member list at `in-task-maintenance.md` went stale the moment the exempt class widened, and it was the site an agent consults for exactly that obligation — a blocking review finding. Both satellites are now pure pointers.
